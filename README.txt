SITO RISTORANTE — STARTER KIT

Struttura:
- index.html
- css/style.css
- js/main.js

Apri index.html nel browser per vedere il sito.

Da personalizzare:
1. Sostituisci NOME con il nome del ristorante.
2. Inserisci foto reali nelle sezioni hero e locale.
3. Modifica telefono, indirizzo e orari.
4. Inserisci il menu reale.
5. Aggiungi i link Instagram/Facebook.
6. Per una prenotazione online, collega il pulsante a WhatsApp, telefono o al servizio di booking scelto.

Il sito è volutamente senza framework: HTML, CSS e JavaScript sono separati e facili da modificare.
